# SIH26127 Trajectory Engine

Backend engine for multi-camera ANPR, vehicle trajectory reconstruction, and urban traffic analytics.

The engine processes vehicle observations from multiple cameras and provides persistent vehicle identities, complete trajectories, movement analytics, traffic insights, anomaly detection, alerts, and GIS-ready data.

Development camera coordinates and graph are fixtures for testing only, not authoritative city road geometry.
